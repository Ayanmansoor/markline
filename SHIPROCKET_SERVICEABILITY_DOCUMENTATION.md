r# Shiprocket Serviceability API Documentation & Token Strategy

This document details the database schema, token caching architecture, Vercel Serverless deployment strategy, and sample API payloads for the **Shiprocket Courier Serviceability** feature.

---

## 1. Supabase Database Schema (`public.shiprocket_token`)

The Shiprocket Bearer Authentication Token is stored in Supabase under `public.shiprocket_token`:

```sql
create table public.shiprocket_token (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  token_value text null,
  expires_at date null,
  constraint shiprocket_token_pkey primary key (id)
) TABLESPACE pg_default;
```

---

## 2. Hybrid Token Caching Strategy (Vercel + Supabase)

To maximize performance, reduce database queries, and ensure 100% reliability when deployed on Vercel Serverless Functions:

```
[ User Pincode Check ] 
       │
       ▼
[ Next.js Serverless Route: /api/check-serviceability ]
       │
       ├── 1. Check Server RAM (Warm Execution) ⚡ 0ms
       │      (If valid in RAM -> Use Token immediately)
       │
       └── 2. If Cold Start / RAM Miss 🚀 ~10ms
              (Query Supabase 'shiprocket_token' for expires_at >= NOW())
              └── Populate Server RAM for subsequent user requests
```

### Why this strategy is ideal for Vercel:
* **Zero Duplicate Authentication Calls**: One token generated and stored in Supabase serves all users across all Vercel instances.
* **0ms Latency on Warm Requests**: In-memory RAM cache handles 99% of requests instantly.
* **Cold Starts Handled**: If a Vercel function cold-starts, it reads the active token from Supabase in ~10ms.

## 3. Shiprocket External Serviceability API

### HTTP Request
```bash
curl --location 'https://apiv2.shiprocket.in/v1/external/courier/serviceability/?pickup_postcode=110001&delivery_postcode=175019&weight=0.5&cod=1' \
--header 'Content-Type: application/json' \
--header 'Authorization: Bearer {{token}}'
```

### Query Parameters:
* `pickup_postcode`: Origin warehouse PIN code (default `110001` or `SHIPROCKET_PICKUP_PINCODE` env var).
* `delivery_postcode`: Customer's destination PIN code (e.g. `175019`).
* `weight`: Package weight in kg (default `0.5`).
* `cod`: `1` to test Cash-On-Delivery availability.
